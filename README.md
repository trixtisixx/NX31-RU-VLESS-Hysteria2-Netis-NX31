# NX31-RU — VLESS и Hysteria2 на роутере Netis NX31

NX31-RU ставится на роутер **Netis NX31** с заводской прошивкой (OpenWrt 21.02) или с официальной OpenWrt 23.05 / 24.10. После установки зарубежный трафик всех устройств сети идёт через ваш сервер **VLESS** или **Hysteria2**. Российские сайты при этом открываются напрямую, как раньше.

Роутер **не перепрошивается**: загрузчик и заводская прошивка не меняются, сброс настроек не делается. NX31-RU — это несколько файлов и служб поверх заводской системы, и их можно полностью удалить одной командой.

> **Проверено на реальном роутере.** Версия 1.1.0 установлена и работает на Netis NX31 с OpenWrt 24.10.5. На заводской прошивке (OpenWrt 21.02) и на OpenWrt 23.05 на устройстве пока не проверялась. Подробности — в [docs/TESTING.md](docs/TESTING.md).

> При первой установке оставьте включённой «проверку с перезагрузкой»: если после перезагрузки что-то пойдёт не так, установщик сам вернёт роутер в исходное состояние.

## Быстрый старт

1. Скачайте архив `NX31-RU-1.1.0.zip` из раздела **Releases** этого репозитория и распакуйте его в любую папку.
2. Подключите компьютер к роутеру кабелем или по Wi-Fi.
3. Запустите **`nx31.bat`** (или `NX31-RU.exe` — это одно и то же).
4. Нажмите Enter на вопросы об адресе (192.168.1.1) и пароле SSH (по умолчанию `Test1234`).
5. Вставьте ссылку на сервер или адрес подписки (можно пропустить и добавить потом).
6. Подождите 1–3 минуты и согласитесь на проверку с перезагрузкой.
7. Откройте `http://192.168.1.1/vless.html`.

Подробно, по шагам: [docs/INSTALL.md](docs/INSTALL.md).

## Что умеет

**Маршрутизация.** Напрямую идут:

- российские IP-адреса (база GeoIP RU, около 8 700 сетей);
- российские сайты (около 870 доменов: Яндекс, VK, Госуслуги, Ozon, Wildberries, 2ГИС, банки, все сайты в зонах .ru, .su и .рф);
- локальная сеть и сам роутер.

Всё остальное идёт через прокси.

**Подписки и ссылки.**

- Принимаются ссылки `vless://`, `hysteria2://` (`hy2://`) и подписки `https://…` в любом формате: список ссылок, Base64, Clash YAML, JSON Xray.
- Подписок может быть несколько, у каждой своё название.
- Строки с ошибками пропускаются, но видно, сколько и почему.

**Проверка серверов.** Каждый сервер проверяется по-настоящему: DNS → порт → подключение по протоколу → HTTP-запрос через прокси. Результат — «Работает · 85 мс», «Не отвечает» или «Ошибка подключения».

**Автоматический обход сбоев.**

- Если сервер перестал работать, NX31-RU пробует другие серверы.
- Если не работает ни один, интернет сразу переходит на прямое подключение, и вы видите уведомление.
- Когда сервер снова заработает, прокси включится сам.
- Российские сайты, локальная сеть, DNS и DHCP при этом работают всегда.

**DNS без утечек.** Все устройства сети пользуются DNS роутера, даже если на устройстве вписан другой DNS.

- Российские домены разрешаются через Яндекс DNS напрямую.
- Остальные — через DoH 1.1.1.1 внутри прокси.

**Веб-интерфейс** `http://192.168.1.1/vless.html`: на русском, работает на телефоне. В меню стандартной админки появляется пункт «VLESS» (заводская прошивка) или «Службы → NX31-RU (VLESS)» (LuCI в OpenWrt 23.05/24.10).

- Пароля нет, но интерфейс открывается только из домашней сети.
- Он защищён от CSRF и DNS rebinding.
- Произвольные команды через него выполнить нельзя.

**IPv6.** Выход устройств в интернет по IPv6 закрыт, чтобы сайты не открывались в обход прокси. Устройства автоматически переходят на IPv4.

## Прошивки

| Прошивка | Firewall | Как работают правила | На роутере |
|---|---|---|---|
| Официальная OpenWrt 24.10 | fw4, nftables | своя таблица `inet nx31`; таблица fw4 и настройки firewall не меняются | **проверено** (24.10.5) |
| Официальная OpenWrt 23.05 | fw4, nftables | так же, как на 24.10 | не проверялось |
| Заводская Netis (OpenWrt 21.02) | fw3, iptables | свои цепочки `NX31_*`, GeoIP RU в ipset | не проверялось |

Перед установкой на OpenWrt 23.05/24.10 ядро роутера проверяет все правила NX31-RU командой `nft -c` (проверка без применения). Если ядро их не примет, установка остановится, роутер не изменится.

Всё нужное лежит в установщике, интернет на роутере для установки не нужен. Для OpenWrt 24.10.5 в комплекте есть модуль ядра TPROXY (UDP через прокси). Он ставится, только если ядро роутера в точности совпадает с официальным, и удаляется вместе с NX31-RU.

## Поддерживаемые протоколы

| | Поддерживается | Не поддерживается |
|---|---|---|
| VLESS — транспорт | TCP, WebSocket, gRPC, HTTPUpgrade, XHTTP | HTTP/2 (удалён из Xray), mKCP, QUIC |
| VLESS — защита | TLS, REALITY, XTLS-Vision (с TCP), VLESS Encryption (ML-KEM) | VLESS совсем без шифрования к серверам в интернете (Xray запрещает), устаревший `security=xtls` |
| Hysteria | Hysteria2, обфускация salamander, диапазоны портов | Hysteria v1 |
| Прочие протоколы | — | VMess, Trojan, Shadowsocks, TUIC, WireGuard |

Ссылка с `insecure=1` (отключённая проверка сертификата) добавляется с предупреждением: Xray больше не умеет отключать эту проверку. Если у сервера самоподписанный сертификат, в ссылке нужен его отпечаток `pcs=` (для VLESS) или `pinSHA256=` (для Hysteria2).

Движок — **Xray-core 26.10.31** (официальная сборка). Sing-box не используется: на флеш-памяти роутера для него нет места.

## Защита от «кирпича»

Ни один шаг установки не трогает прошивку, загрузчик, настройки сети (`/etc/config/network`), Wi-Fi, пароли и SSH. Кроме того:

1. **Перед установкой** проверяется всё: модель, версия OpenWrt, свободная память и флеш-память, DNS, интернет. Если что-то не так, роутер не меняется вообще.
2. **Исходные настройки** сохраняются один раз, при первой установке, и восстанавливаются при удалении.
3. **Если установка или проверка после неё не прошли**, выполняется автоматический откат.
4. **Если прервалось SSH-соединение**, установка на роутере доводится до конца, а установщик дожидается результата.
5. **После любого сбоя** — падения Xray или менеджера, нехватки памяти — интернет переходит на прямое подключение. Дополнительно за менеджером следит отдельный «сторож».
6. **Если роутер 4 раза подряд перезагрузится**, не проработав 3 минут, включается **безопасный режим**: прокси не запускается, роутер работает как заводской.
7. **Правила firewall** касаются только трафика из домашней сети. Доступ к админке, SSH и DHCP через них потерять нельзя. На OpenWrt 23.05/24.10 все правила лежат в отдельной таблице `inet nx31` и применяются одной транзакцией: при ошибке не меняется ничего.
8. **Временные файлы DNS** лежат в оперативной памяти. Если файлы проекта пропадут, dnsmasq просто вернётся к DNS провайдера.

## Для разработчиков

```
src/nx31d/        менеджер (Go): подписки, проверки, failover, DNS, API веб-интерфейса, CGI
src/launcher/     установщик NX31-RU.exe (Go, встроенный SSH-клиент)
router/files/     файлы, которые ставятся на роутер (init-скрипты, fw.sh, setup.sh, vless.html)
installer/        nx31.bat, nx31-uninstall.bat
tools/build.py    сборка пакета и установщика
tools/geosite_ru.py  список российских доменов из geosite.dat
tools/fwtest.sh   проверка правил firewall (iptables и nftables) с заглушками, без роутера
router/opkg/      модули ядра TPROXY для OpenWrt 24.10.5 (ставятся без интернета)
```

Сборка (нужны Python 3.8+ и Go 1.26):

```bash
python tools/build.py --test
```

`--test` запускает автотесты Go и `tools/fwtest.sh`. Тесты с настоящим Xray запускаются, если указать `NX31_TEST_XRAY=путь/к/xray`; подробности — в [docs/TESTING.md](docs/TESTING.md).

Результат появится в `dist/`: пакет для роутера `nx31-payload.tgz` и папка/архив `NX31-RU-<версия>` с установщиком.

Лицензия Xray-core — MPL-2.0. Список доменов взят из v2fly/domain-list-community (MIT), база GeoIP — из ipverse/country-ip-blocks.
